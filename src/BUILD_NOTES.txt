Halliseum Control Center v0.5.0 VISUAL COACH

NEW:

FACTOR GOLF SIM CONTROL CENTER v0.8.1
------------------------------------
- Stabilization release. This is not a 1.0/final-polish build.
- Coach Mode range navigation now tries UI Automation, then Windows built-in OCR against the live GSPro window, then saved coordinates only as the final fallback.
- Range navigation writes range_nav_status.json, range_nav_debug.json, and range_nav_ocr.txt for machine-specific diagnostics.
- Connector minimization now enumerates all top-level windows, supports preferred connector PID/path, recognizes VGPconnect/ForesightForm signatures, and writes connector_window_diagnostics.json.
- Club Cheat Sheet watcher now observes GSPro's default I/K/U club shortcuts while GSPro is foreground. It tries GSPro UI first and can infer the adjacent club from a configurable club order before the next shot is hit.
- Settings ComboBoxes now use a full dark-theme template. Current/selected values use gold text; popup items remain dark with white normal text and gold selected/highlighted text.
- Performance help copy now explains Recommended Carry in golfer language.
- Home screen now reserves AI CADDY as COMING SOON. No caddie advice is enabled yet.
- Internal Halliseum filenames/paths remain for compatibility.
