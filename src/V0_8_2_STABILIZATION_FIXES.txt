FACTOR GOLF SIM CONTROL CENTER v0.8.2
=======================================

Purpose: repair the three v0.8.1 Coach Mode failures observed on the actual simulator PC.

FIXES
-----
- Coach Mode starts range navigation immediately after launching GSPro instead of waiting behind connector/other setup work.
- One-time v0.8.2 migration re-enables AutoOpenDrivingRange, MinimizeForesightConnector, ClubCheatSheetEnabled and the initial Driver prompt for installs that may have preserved old false values.
- Range navigation recognizes the exact manual route: Practice -> GS Pro Practice Range.
- Connector minimizer starts immediately and recognizes Visual Golf / VisualGolf / VGPconnect / ForesightForm signatures.
- Connector watch runs longer and writes a dedicated minimize status file.
- Club Cheat Sheet no longer waits up to 40 seconds for range navigation before listening for pedal changes.
- Initial Driver Cheat Sheet appears independently shortly after Coach Mode starts.
- Confirmed pedal mapping: K = Club Up, I = Club Down.
- Club changes update session_state.json immediately.
- Key polling tightened from 45 ms to 10 ms to reduce missed pedal taps.
- Worker launch logging added so a future failure shows whether each worker actually started.
